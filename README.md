# 网页侦探脚本中心
[网页侦探](https://webdiff.perk-net.com/)是一款多功能的网页变化监控提醒软件。
支持多种监控任务类型，从盯网页元素、巡检 HTTP 接口与 RSS 更新、IMAP/POP3 邮件收取，到 Ping 连通与延迟、域名 WHOIS 与 SSL 证书到期，再到自定义脚本。一个工具，轻松搞定！

可从本项目中快速的获取完善好的网页侦探任务或自定义脚本代码。

## 导入网页侦探任务
1. 下载 .webdiff 后缀的脚本文件
2. 主界面上点击“导入”按钮
3. 选择下载好的脚本文件
4. 确认导入选项：通知渠道，通知模板
